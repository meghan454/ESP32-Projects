# ESP32 Projects

A collection of hands-on embedded systems projects developed using the ESP32 microcontroller, sensors, and electronic components.

## Projects

### 1. Smart Environment Monitoring System

An ESP32-based system that monitors temperature and humidity using a DHT22 sensor and displays real-time readings on an OLED display. A buzzer alerts the user when the temperature exceeds 30°C or humidity exceeds 70%.

**Components used:** ESP32, DHT22 sensor, OLED display (SSD1306), buzzer.

[View Project Documentation](./01_Smart_Environment_Monitoring_System/)

## Skills Practiced

- ESP32 programming using Arduino IDE
- Sensor interfacing
- I²C communication with OLED displays
- Real-time environmental monitoring
- Threshold-based alerts
